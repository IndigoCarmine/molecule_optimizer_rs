# GAFF 実装メモ: 出典と未解決の点

`src/ff/gaff/` の実装が何を根拠にしているか、どこが未確認かをまとめる。
2026-11-10 時点。

## 文献で確定した点

### 角度の力の定数（式 5）

- GAFF 2004 の式 (5) は誤植で、Erratum 2005 が訂正している。正しい形は次のとおり。

  ```text
  K_θ = 143.9 · Z_i · C_j · Z_k · (r_ij + r_jk)^-1 · θ^(-1/2) · exp(-2D)
  D   = (r_ij - r_jk)² / (r_ij + r_jk)²
  ```

  元の論文は θ の指数を −2 と印刷していた。θ はラジアン。
- この式は GAFF 1.81 の表の角度 5299 個を 0.1% 以内で再現する（表の値 / 式の値の中央値 1.0000）。
  つまり GAFF 1.81 の角度の力の定数は、この式から作られている。
- GAFF 2.11 / 2.2.30 の表は作り直されていて、式より平均で 25% / 13% 硬い。
- 対応: `estimate::angle_force_constant` を訂正後の式に直し、以前入れていた「表に合わせた倍率補正」を削除した。
  `GaffParams::angle_rule_ratio()` で表と式の比を確認できる。

### dat の列の意味

Cornell 1995 の Table 14 の脚注と書式ページで確認した。実装は変更不要。

| 項目 | 内容 | 出典 |
|---|---|---|
| 二面角のエネルギー | `(PK / IDIVF) · (1 + cos(PN·φ − PHASE))` | 書式ページ |
| PK | `V_n / 2` | Cornell 1995 Table 14, 書式ページ |
| IDIVF | 障壁を分ける結合経路の数（中央 2 原子それぞれの結合数の積）。例: X-C-CA-X は 4 経路で各 14.5/4 | Cornell 1995 脚注 f, Weiner 1984 |
| 負の PN | 同じ結合まわりに項が続くことを示す。計算には絶対値を使う | Cornell 1995 脚注 i, 書式ページ |
| improper | 割り算（IDIVF）をしない | 書式ページ |
| 個別の二面角 | 汎用（X-j-k-X）より優先する | Weiner 1984 |
| vdW | `R*_ij = R*_i + R*_j`、`ε_ij = sqrt(ε_i ε_j)` | Cornell 1995 脚注 j, k |

### 非結合相互作用

- 3 結合以上離れた原子対と、別分子の原子対だけを計算する（Cornell 1995）。
- 1-4 のスケールは静電 1/1.2、vdW 1/2（Cornell 1995, GAFF 2004 の Methods）。
- 結合の指数 m は 4.5（GAFF 2004）。Amber サイトの説明ページには 4.0 とあるが、4.5 で表の c3-c3 を再現できる。

## 未解決の点

### 1. 水素の型（h1〜h5）の「電子求引基」

- GAFF 2004 には定義がない。
- Cornell 1995 は、sp3 C–H について「electronegative (O, N, F, S)」の置換基ごとに R\* を 0.1 Å 減らす（H1〜H3）、
  sp2 C–H について電気陰性な隣接原子ごとに 0.05 Å 減らす（H4, H5）、正電荷基の隣は別の型（HP、GAFF の `hx`）としている。
- 現在の実装は N, O, F, Cl, Br を数える。S を数えていない点が Cornell 1995 と違い、Cl と Br を数える点は Cornell 1995 に根拠がない。
- h4 / h5 を芳香族に限らず非 sp3 炭素全般に使う点は Cornell 1995 と合っている。
- カルボニル炭素上の H を `ha` にしているのは GAFF 2004 の Fig. 1a（分子 4）による。
- 解決策: Wang 2006 で GAFF の定義を確認し、`typer::ELECTRON_WITHDRAWING` を直す。入手できなければ参照値（下の 6）で決める。

### 2. 原子型の細かい判定

- 「純粋な芳香族」（`ca` / `nb` / `pb`）と「共役系の内側の原子」（`cc`, `ce`, `cg` など）の判定は、
  GAFF 2004 の Table 1・本文・Fig. 1 と dat の説明文から組み立てたもので、厳密な定義は未確認。
- 末端の S は GAFF 2004 では `s2`、dat の説明では `s`。dat に `c-s` の結合があるので `s` にしている。
- `p4` / `px` は「3 置換」で判定している。Fig. 1 の該当分子は H の有無を読み取れず、図との一致は未確認。
- `hb`（説明が "H in a bridage" のみ）と `Cu` は割り当てない。
- 解決策: Wang 2006 を入手して照合する。

### 3. improper の原子の並びと優先順位

- 書式ページ: 汎用の行（X 入り）を先、個別の行を後に書く。逆にすると汎用が個別を上書きする。つまり後の行が勝つ。
- 検索結果に出た 2006 年の D. Case の投稿の要約: 中心原子を 3 番目に置き、残り 3 原子は原子型のアルファベット順、同じ型は原子名順。
  投稿の本文は読めていない。
- 現在の実装: ワイルドカードが少ない行を優先し、同点なら先の行。型指定の位置を先に埋め、残りは原子番号順。
- 解決策: 並びを原子型のアルファベット順に、同点の扱いを後の行優先に変える。非対称な中心でエネルギーが少し変わるので、参照値で確かめてから変える。

### 4. 表にない sp2 中心の improper

- Weiner 1984: 2 回対称の improper は sp2 原子の平面性を保つためのもの。Amber の FAQ にも「sp2 原子はすべて improper を持つべき」とある。
- 現在の実装は dat に行がある中心にしか improper を付けない。アルケンやフラン・ピロールの CH には付かない。
- 解決策: 表にない sp2 中心に既定の improper を付ける。既定値（1.1 kcal/mol, 180°, n = 2 という記憶がある）の出典は未確認。

### 5. クーロン定数

- どの論文にも数値はない。現在の既定は物理定数から求めた 332.0637 kcal·Å/(mol·e²)。
- Amber のプログラムは 18.2223² = 332.0522 を使う（Amber のメーリングリストと FAQ）。相対差は約 3.5e-5。
- 解決策: Amber と数値を突き合わせるときは `GaffBuilder::coulomb_constant` を 332.0522 にする。既定値を変えるかは未決定。

### 6. 参照実装との比較がない

- 現在のテストは、論文と dat から導ける値（Fig. 1 の型、Table 5 の存在確認、エタンの手計算、数値勾配）だけ。
- 解決策: AmberTools で数分子の原子型と項別エネルギーを出力し、テストの参照値にする。1〜4 を決める材料にもなる。

### 7. 部分電荷

- GAFF 2004 は RESP（HF/6-31G\*）か AM1-BCC を使う。どちらも量子化学計算が要るので実装していない。
- 現在は利用者が渡す。渡さなければ静電項なしで、`GaffBuilder::assign` が警告を返す。
- 候補: AM1-BCC を近似する学習モデル（EspalomaCharge、MIT ライセンス）。移植は別の大きな作業になる。
- 当面の解決策: MOL2 の電荷をそのまま渡せる入口を足す。

### 8. Table 5 と dat の差

- GAFF 2004 の Table 5（汎用二面角 200 個）のうち、`X-ca-n3-X`、`X-ne-py-X`、`X-nf-py-X` は gaff.dat（1.81）にない。
- 現在の実装では、対の型への読み替えと基本型へのフォールバックで拾えなければ欠損として記録する。

### 9. GAFF 2.x の補完

- 角度の式は GAFF 2.x の表と合わない（上記）。結合の式も同様の可能性がある。
- 解決策: GAFF 2.x で推定値を使った結合・角度は `GaffAssignment` に記録されるので、使う側で確認する。GAFF 2.x 用の規則の出典は見つかっていない。

### 10. 未対応の機能

- `FastBuilder` の近似モード、テンプレートキャッシュ、soft-core は GAFF に未対応。exact モードは動く。
