# GAFF parameter files

Copied unmodified from AmberTools 26.0 (`dat/leap/parm/`), taken from the
conda-forge package `ambertools-26.0-cuda_None_nompi_py313h2762e8a_101`.

| File          | Version                  |
|---------------|--------------------------|
| `gaff.dat`    | GAFF 1.81 (May 2017)     |
| `gaff211.dat` | GAFF 2.11 (May 2016)     |
| `gaff2.dat`   | GAFF 2.2.30 (Oct 2025)   |

License: public domain. The AmberTools `LICENSE` file states:

> The force field parameter files in the "../dat/leap" subdirectory have
> been placed in the public domain by their authors.

Only these parameter files are public domain. The rest of AmberTools
(antechamber, its `dat/antechamber/*.DEF` atom-typing rules, sqm, ...) is
GPL-3 and must not be copied or ported into this crate.

References: J. Wang, R. M. Wolf, J. W. Caldwell, P. A. Kollman, D. A. Case,
"Development and testing of a general Amber force field",
J. Comput. Chem. 25, 1157-1174 (2004).
